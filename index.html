Frequently asked

How does order confirmation work?

After checkout, SYVRA generates a unique order ID and opens WhatsApp with a pre-filled order summary. The customer taps Send to deliver the order to your WhatsApp.

Can customers sign in with Google?

Yes. The site includes Firebase Google Authentication wiring. Add your own Firebase web configuration in script.js and enable Google in Firebase Authentication.

Will the store work on GitHub Pages?

Yes for the storefront, cart, checkout and WhatsApp flow because they are client-side. Google authentication requires a Firebase project and your live domain added to Firebase's authorized domains.

Are payment details stored?

This starter store does not collect card numbers. It is designed to avoid putting sensitive payment secrets in frontend JavaScript. Add a trusted payment provider later if you need online payments.
