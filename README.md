# SYVRA Online Store

GitHub Pages-ready SYVRA storefront.

## Images
All product artwork is stored locally in `assets/` and uses relative paths, so it works on GitHub Pages without external image hosting.

## GitHub Pages
Upload the contents of this folder to the repository root. Make sure `index.html` is directly in the root, then enable **Settings → Pages → Deploy from a branch → main → / (root)**.
